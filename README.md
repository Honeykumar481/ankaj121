# Ankaj Rana — Portfolio

One-page portfolio built with Next.js (App Router) and TypeScript. No UI libraries; styles live in `app/globals.css`.

## Run

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

## Edit content

All text comes from `data/resume.ts`. Before deploying, set:
- `SITE_URL` to your domain
- `profile.linkedin` to your LinkedIn profile URL

Replace `public/Ankaj_Rana_Resume.pdf` whenever you update your CV.

## Deploy

Push to GitHub and import the repo on Vercel; no configuration needed.
